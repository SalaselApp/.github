# من نحن

[![Web App](https://img.shields.io/badge/Web%20App-Salasel-6945ff)]()
[![الوصف المختصر](https://img.shields.io/badge/الوصف-مساحة%20للعمق%20بدلاً%20من%20السرعة-ff0df9)]()

**Salasel App** هو تطبيق ويب يقدّم قوائم تشغيل مختارة بعناية من يوتيوب لبناء الإنسان،
مع ملاحظات ذاتية مرتبطة بزمن كل مقطع داخل الفيديو، ونظام تتبّع للتقدّم في القوائم ومقاطعها.

تنطلق **سلاسل** من فهم عميق لاحتياجات الشباب المعاصر، وتقدّم محتوى يخاطب الإنسان ككل عبر أربعة مرتكزات أساسية:

- الفطرة السليمة
- الإيمان الإسلامي
- النفس الإنسانية
- الصحة الجسدية والنفسية

سلاسل ليست محتوى عشوائياً، بل رحلة بناء نحو إنسان متوازن يفهم فطرته، ويلتزم بإيمانه، ويطوّر نفسه، ويحافظ على صحته.
